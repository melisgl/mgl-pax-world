This repository holds the documentation generated by
`mgl-pax:update-pax-world`. Go and see the docs at
<http://fixnum.com>.

To have your project included, file an issue with the name of your
project and where to get it. If you can, provide an URL to its git
repository, as this makes links to source locations use the actual git
version instead of a moving target such as `master`.

For the list of ASDF systems included, see `update-pax-world*` in
`update-pax-world.lisp`.
